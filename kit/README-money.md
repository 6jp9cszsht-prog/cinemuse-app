# 未明 収益キット — 副業化の配管一式

本番サイト(cinemuse-appリポジトリ)を壊さず「足すだけ」で、3系統の収益・配信を有効化します。
適用は `python3 kit/apply.py` 一発(冪等・既存の夜と日付には一切触りません)。

## ① X自動投稿(告知の自動化)

feed.xml が更新されるpushのたび、最新の夜をXへ自動投稿します。

1. developer.x.com で無料アカウント → アプリ作成(Free tierで月500投稿、週1なら余裕)
2. App permissions を **Read and write** にしてから、4つのキーを発行
3. リポジトリ Settings → Secrets and variables → Actions に登録:
   `X_API_KEY` / `X_API_SECRET` / `X_ACCESS_TOKEN` / `X_ACCESS_SECRET`
4. テスト: Actions → announce → Run workflow(投稿済みならスキップされます)

キー未設定の間は自動でスキップされ、サイト公開には影響しません。

## ② メール購読(読者資産化)

購読セクションにメールフォームを設置済み。配信は Buttondown を推奨
(無料〜100購読者、Stripe連携で将来の有料購読にもそのまま移行可)。

1. buttondown.com でアカウント作成(ユーザー名を決める)
2. index.html 内の `BUTTONDOWN_USERNAME` を自分のユーザー名に置換 → push
3. 配信: BackになったらRSS自動配信機能をON(プラン要件は管理画面で確認)。
   自動化が使えない間も、週1なら手動で十分 — 金曜に記事URLを貼った1通を送るだけ(3分)

## ③ 支援 + 書架(直接収益)

「支援と書架」セクションを設置済み。差し替えは3つ:

- `SUPPORT_URL` → Ko-fi か OFUSE(日本語圏なら OFUSE も好相性)のページURL
- `BOOTH_URL_VOL1/2/3` → BOOTHの出品URL。手元の3巻PDF(未明_巻一〜三)をそのまま出品。
  価格は「¥0+ブースト(投げ銭)」方式が哲学ブログの空気に合います。¥300固定でも可
- 巻三は15〜17夜の公開後に「第十三夜—第十八夜」の完成版へ差し替え推奨
